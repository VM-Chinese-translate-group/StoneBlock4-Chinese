| 范围 | 结果 |
| --- | --- |

| 停用与再次启用资源包 | 停用后恢复先前控件与背景；再次启用后恢复 StoneUI。修复并复测过停用后的背景缓存缺图警告。 |

| 日志 | 最终验收没有发现 StoneUI 缺图、Mixin 或运行异常；不代表整合包其他模组的历史日志全部无错误。 |

原版子设置页和 Iris 等部分补充检查使用的是同一资源包及 Java 类字节完全相同的前一版 JAR；随后最终 JAR 只增加了 1×1 透明背景兜底图，并完成冷启动、资源包停用/启用、存档和代表性模组页面复测。

曾枚举 228 个已注册的模组配置菜单入口，**没有逐个目视打开全部 228 个页面**。本包不强制统一第三方自定义界面，未来模组新增或改动界面仍需复验。不宣称所有菜单都被覆盖。

## 本 PR 的交付校验

`python verify.py` 验证发布 ZIP/JAR 的 SHA-256、46 项 ZIP 成员及展开资源的一致性、桥接资源、12 个精确原版设置类和客户端 Mixin 范围。`python build.py`、`python bridge/build.py ...` 后运行 `python verify.py --rebuilt`，按成员字节验证重建归档与已验收产物一致。

此次提交的 UI 文件全部位于 `extras/StoneUI`，并提供根 README 链接；没有向 `CNPack` 添加任何 UI 资源、模组或配置，没有更改发布工作流、自动安装流程、资源包优先级或启用状态。另一个独立提交仅运行上游既有脚本，同步两份汉化包元数据的格式及共享名称，满足仓库已有的 `Sync Pack Info` 检查；不会安装本附加包。
