# 1.24.1 汉化与首页按钮修复

本批改动以 VM 正式版 `1.24.1` 及 `main` 的 `c5577ec22b44c6efde60d7c5457c22a9084ad928` 为基线。正式包 `FTB.StoneBlock.4.1.24.1_V1.zip` 的 SHA-256 为 `55b4b699e5cbc86b58afb235c3fb226c38dc0ef3d150bcb8a6215665cf09a765`：其中 220 个主体文件与 Git 对象逐字相同，额外包含 VMTU 5.3.1。因此，这批问题没有“主分支已修、正式包尚未发布”的版本差异。

改动在既有 VM、I18N / CFPA 译文之上补缺和校订，使用了 AI 辅助整理、译写与检查。既有译文的贡献者归属保留；本批不重新打包整个 I18N / CFPA 汉化包。大批手册尚未逐页人工校审，建议按本说明分组审阅。

## 已修与未修的区别

| 项目 | 基线状态 | 处理 |
| --- | --- | --- |
| 当前任务的文案与悬停文字 | 仍保留本次修正前的值 | 只移植当前章节实际引用的任务语言键，并适配现有章节格式 |
| 英文任务语言文件中的历史键 | 很多对象已不在当前章节中 | 不将历史键缺失当作当前玩家漏译，不补入这些无引用项 |
| 五处任务信息图标 | 仍引用旧 JEI 纹理路径 | 提供当前 JEI 图标的兼容资源，保留任务结构、条件及奖励 |
| 四阶世界引擎手册导航图标 | 仍是失效的旧资源 ID | 仅改导航图标 ID |
| phasorite 隐藏页 | VM 已提供正确的零字节页面 | 不重复修正文；防止后加载的 CFPA 旧页面覆盖它 |
| GuideME 其他页与部分路由器页面 | 当前运行层存在旧图标／分类覆盖 | 用小范围最终资源层保持已审修复，保留自动汉化更新 |
| 首页创建服务器、Discord、周边 | 仍使用英语素材 | 中文像素文字与原石板轮廓，包含普通和悬停状态 |

语言资源比较使用的是“当前原模组 + VM 1.24.1 + 当时已加载的 CFPA”组合。相同内容跳过；资源路径缺失、条目不同与游戏中可见的漏译不是同一个计数，不能把补丁文件数当成全部实测的问题数。

## 范围

`CNPack` 包含普通语言、手册、物品图标／模型兼容、当前任务文字、分组名称、整合包脚本文字和首页三个按钮的修复。语言文件按键合并，保留上游独有条目；手册沿用当前模组的真实路径和格式。首页修改保留原按钮位置、链接、条件及周边按钮的两个显示变体。

脚本以对应 FTB StoneBlock 4 1.24.1 的已验收原文件为基础，保留命令、持久化键、配方与机器参数。两个机器 JSON 调整的是名称／文字的文本组件表达，确保翻译键能按 `translate` 解析。`Statistics.js` 的卸载回调是单独的生命周期修复：世界卸载时释放并清空统计实例，避免卸载后重新创建；它不是新增玩法。

`compat/localization-compat` 保存可选的 Oracle 中文搜索、SimplyTooltips 硬编码标签与 Patchouli 版号兼容源码及已测 JAR。该组件有明确加载器版本要求，**没有默认放入 `CNPack/mods`**，请独立评估。移除它不移除普通译文。

本批不包含通用石板控件、设置背景场景或 StoneUI 桥接模组，也不包含用户存档、options.txt、启动器设置、下载缓存、日志、安装记录和本机备份。

## 与 ParaTranz 同步

当前 `para2github.py` 会重写对应的语言 JSON，任务同步还会从 `Source` 重新生成任务语言与章节文件；仅合并生成文件不能保证下次同步仍保留修正。请在合并前或合并时将对应译文同步到 ParaTranz。手册 Markdown 和普通 JS 不由当前这段语言同步脚本重写。

任务译文的导出记录区分可直接对应的现有源键，以及需要维护者映射的旧章节 `hover` 字段。`CNPack` 的个别图片结构与 `Source` 已有差异，投稿没有用本机自动转换后的整章文件覆盖上游，也没有擅改 `Source` 中的原始任务配置。

可供维护者同步的记录位于 `contributions/1.24.1/paratranz-quests/`，没有代为上传到 ParaTranz。任务语言修改为 78 个既有逻辑键，展开后是 83 条实际变化的字符串；其中 75 条属于后台进度／开发检查章节，8 条属于玩家页面及反应堆、图片格式修正。另有 3 条旧结构悬停文案需要维护者映射源结构。421 个已无当前章节引用的历史键已排除，不能把这些数量写成 78 处或 507 处玩家可见漏译。

最终资源层脚本只用于已确认会被后加载汉化资源盖回的条目和页面。后续 CFPA 更新时，应复核这些定点覆盖，再同步修改普通资源与生成内容，避免长期保留已失效的纠错。

## 验证与边界

本地已有修复曾在 Minecraft 1.21.1、NeoForge 21.1.262、StoneBlock 4 1.24.1 的独立验收存档中完成代表性测试：任务信息图标、当前悬停文案、首页三个按钮及其悬停状态、手册图标和链接、Oracle 中英文检索及页面跳转、资源重载、中文／英文版号切换、保存退出。

投稿移植另核对上游基线、字段级差异、JSON / SNBT 解析、脚本语法、文件哈希及资源路径。可选兼容组件在新目录重编译后，全部 19 个类和资源字节与已测 JAR 一致；ZIP 时间戳可能不同。

这不是对投稿目录重新安装后的整包回归，也不是全部手册和生产链的完整验证。游戏当前安装和用户存档未因本次投稿整理而改动。合并和后续发布前，建议维护者在其标准安装方式与 ParaTranz 同步流程下再验收。
