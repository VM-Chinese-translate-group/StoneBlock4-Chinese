# 通灵钥匙

<ItemImage id="irregular_implements:spectre_key" scale="2" />

<Color id="aqua">通灵钥匙</Color>可以带你进入专属的<Color id="aqua">通灵维度</Color>，房间长宽恰好为一个区块。手持钥匙，持续使用 5 秒后，就会传送到其中。

手持<Color id="aqua">灵胚</Color>右击房间中央的<Color id="aqua">通灵核心</Color>，可以增加房间高度。

想回家时，再次使用<Color id="aqua">通灵钥匙</Color>即可。
