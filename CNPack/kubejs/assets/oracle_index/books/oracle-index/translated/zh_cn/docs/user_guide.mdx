---
title: 使用指南
---

Oracle Index 是一个仅在客户端运行的游戏内文档模组，用来在游戏中展示 [moddedmc.wiki](https://moddedmc.wiki/) 的内容。

模组开发者可以将自己的 Wiki 打包进模组，再由 Oracle Index 在游戏内显示。按 Wiki 快捷键（默认 [H]）即可打开 Oracle Index 界面。
无需任何特殊手册物品。退出界面时，它会记住你上次阅读的位置。

只有在安装了对应模组，且开发者也将 moddedmc.wiki 文档作为 Oracle Index Wiki 一同打包时，才能在此查看该模组的文档。

## 切换模组
界面左侧是当前模组的导航栏。要切换其他模组，点击导航栏上方的模组标题栏，
再从展开的下拉菜单中选择要浏览的模组即可。

## 物品链接
模组开发者可以为游戏内物品添加 Wiki 链接。如果某个物品有对应页面，其提示信息中就会出现一条额外提示。
查看物品提示时按住 [ALT]，即可打开对应 Wiki 条目。

## 语言
如果 Wiki 提供对应翻译，Oracle Index 会自动使用与当前 Minecraft 语言代码完全匹配的内容。页面正文、导航元数据、页面标题、内置控件、提示框与状态消息都可以翻译。

Schema 1 格式的译文位于 `translated/<locale>/`，旧版格式则位于 `.translated/<locale>/`，并保持与基础页面一致的相对路径。若翻译页面或元数据文件缺失，Oracle Index 会回退到基础语言资源。

简体中文搜索优先使用译文，支持中文关键词、英文标题和物品标识。缺译页面会回退到基础语言；选中结果后打开对应页面。
