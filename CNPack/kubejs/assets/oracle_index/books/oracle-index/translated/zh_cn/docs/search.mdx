---
title: 搜索
---

Oracle Index 提供智能搜索。按 [CTRL + ORACLE_HOTKEY]（Ctrl 加 Oracle Index 快捷键），或搜索快捷键（默认未绑定）即可打开搜索界面。查看 Wiki 条目时，
也会显示一个小型搜索图标。

<Callout variant="info">
    搜索还支持数学计算与表达式！
</Callout>

第一次打开搜索界面时，可能需要等待几秒，为可用页面建立索引。简体中文界面使用关键词搜索，
可以输入中文名称、功能词、英文标题或物品标识。名称越具体，越容易找到目标页面；
较短的词也可以搜索，结果会显示中文标题与相关正文片段。其他语言仍使用原有语义搜索。

## 技术细节
原有语义搜索会先将所有基础页面拆分为文本片段，再使用一个小型句子转换模型 all-MiniLm-L6-V2-q，
为每个片段及搜索请求生成嵌入向量。向量存储在内存中；搜索时，将请求的向量与各 Wiki 文本片段的向量进行比较，
把最接近的 N 个结果展示给用户。

此功能使用基于 DJL 框架的 Langchain4j 库。嵌入模型大小约为 15 MB。

## 限制

简体中文搜索会优先索引当前译文，缺少译文时使用基础页面。输入关键词比完整提问更可靠；切换语言或重载资源后会重新建立索引。

嵌入模型和原生运行时会使支持搜索的模组发行包更大。如果安装的平台专用发行包未包含所需运行时，Oracle Index 会提示搜索不可用，并引导使用跨平台发行包。正常浏览 Wiki 不依赖语义搜索。
