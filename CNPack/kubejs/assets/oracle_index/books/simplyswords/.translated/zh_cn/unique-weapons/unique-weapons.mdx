# 什么是独特武器？

独特武器是简易刀剑中机制最丰富的武器。每把都有固定的武器类型，以及标志性的被动、触发式或主动能力。此处列出的属性均为完全觉醒后的默认值，可通过配置修改。

# 寻找独特武器

符合条件的箱子，包括许多模组结构中的箱子，都有概率出现独特武器。默认基础概率为 **0.05%**。每位玩家独立计算保底：连续 **25** 次符合条件的尝试未出货后，此后每次未出货都会将概率提高 **0.2 个百分点**，最迟在第 75 次符合条件的尝试中保证获得独特武器。保底进度属于每位玩家个人，因此也适用于进度各不相同的多人服务器。

凋灵和末影龙默认掉落独特武器的概率分别为 **5%** 与 **50%**。默认不会向村庄战利品中添加独特武器。所有概率、适用的战利品表、禁用武器和保底阈值均可配置。

启用觉醒系统时，自然掉落的独特武器从觉醒 0 级开始。在符文锻炉中加入最多八块符文石板，即可恢复它们的力量。

# 强能容器

对主题相符的方块使用强能容器，可得到确定的一把独特武器。手持容器时，会获得附近相关方块的提示。例如：铁块对应雷神之锤，铜灯对应风暴之刃，末地传送门框架对应星阙，灵魂火对应沉眠的巫妖巨剑。

# 修复与测试

模组自带的独特武器使用符文石板修复。管理员可以执行以下命令，测试当前配置的战利品生成流程，且不会改变玩家的保底进度：

```
/simplyswords loot_test <loot_table_id> <rolls>
```

要测试实际容器，可用 `/simplyswords loot_test_chest <loot_table_id> [count]`
获取使用指定战利品表的箱子。执行 `/simplyswords pity ignore_regions true` 后，
在本次登录期间，即使反复在同一地点放置新的箱子，
也能推进保底进度；`/simplyswords pity status` 可显示当前计数。

独特能力与镶嵌宝石的能力都会随觉醒等级增强。独特能力默认要到觉醒 4 级才解封；完整说明请参阅觉醒与符文锻炉章节。
