---
title: 武器固有特性
icon: simplyswords:runic_longsword
---

**固有特性**是由武器类型决定的永久加成。简易刀剑的常规武器、符文武器和独特武器都能随机获得固有特性。将鼠标悬停在武器上并按住 **Alt**，即可查看其完整数值范围。

| 武器类型 | 固有特性 | 默认范围 |
| --- | --- | --- |
| 细剑、矛 | 无视护甲的概率 | 15–35% |
| 弯刀 | 命中时掠夺额外战利品的概率 | 1–3% |
| 长柄刀、巨斧、戟 | 施加流血的概率 | 10–60% |
| 三叉刺、匕首 | 背刺伤害加成 | 20–40% |
| 阔剑、长剑 | 招架来袭伤害的概率 | 5–15% |
| 巨锤 | 每次命中削减的护甲比例 | 2–10% |
| 锤 | 每次命中削减的护甲比例 | 2–6% |
| 武士刀 | 造成双倍伤害的概率 | 5–15% |
| 环刃、双头剑 | 命中时获得攻击速度加成的概率 | 5–25% |
| 长柄镰 | 处决低生命值敌人的概率 | 5–15% |
| 战刃 | 攻击两次的概率 | 5–15% |

附属模组的武器只要使用了可识别的物品名称，或加入对应的简易刀剑固有特性物品标签，也能获得固有特性。配置中可以全局关闭固有特性。
