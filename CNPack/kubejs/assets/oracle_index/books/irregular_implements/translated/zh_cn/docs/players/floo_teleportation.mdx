
# 飞路传送

**飞路传送**是一种在飞路壁炉之间移动的传送机制。

## 飞路壁炉

先在世界中搭好砖块结构，再对其使用飞路牌。砖块会转化为飞路砖块，共同组成一座壁炉。

壁炉可以命名，传送时就用这个名字指定目的地。先在铁砧上给飞路牌改名，用它创建的壁炉便会采用这个名字。

壁炉并非必须有名字，但未命名的壁炉无法作为目的地。你仍然可以从它出发，前往其他壁炉！

## 使用方法

站在飞路壁炉上，在聊天中说出另一座壁炉的名字。只要手中拿着[飞路粉](@irregular_implements:floo_powder)，或物品栏中放着装有飞路粉的[飞路袋](@irregular_implements:floo_pouch)，就会传送到对应壁炉。

只能前往同一维度内的壁炉。

名字不必一字不差，只要足够接近，系统也能识别。

身边没有可用于出发的壁炉时，可以改用[飞路指示物](@irregular_implements:floo_token)！
