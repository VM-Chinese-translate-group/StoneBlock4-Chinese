# 结界矩阵

结界矩阵是 MFFS 的区域防御机器。

它可以限制周围玩家或实体的行为，例如自动击杀进入区域的生物与玩家，或阻止未授权玩家操作其他机器。

## 运行原理

结界矩阵周围分为两个区域：**作用区**和**警告区**。

作用区由矩阵向外延伸，其半径格数等于已安装的[尺寸模块](@mffs:scale_module)数量。默认情况下，警告区是从作用区边缘再向外延伸 3 格的同心球壳。

玩家进入警告区时，会收到已进入矩阵扫描范围的提示。不想亲身测试矩阵装了什么模块的话，最好不要再靠近。

没有模块的结界矩阵基本不起作用；安装合适的模块后，它就能成为强大的防御系统。
