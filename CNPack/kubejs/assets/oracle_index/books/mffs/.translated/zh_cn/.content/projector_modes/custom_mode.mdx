# 自定义模式

自定义模式最为灵活，可以投射任意形状或结构的力场。先用模式物品分析并保存你搭建的方块结构，[投影仪](@mffs:projector)就能生成形状完全一致的力场。从桥梁、房屋到整座堡垒，只要能搭出来，就能投射！

<PrefabObtaining />

## 使用方法

手持自定义模式物品，依次对世界中的两个方块使用，选定待分析立体区域的两个对角点。坐标会分别记为“第一位置”和“第二位置”。随后潜行使用，让模式物品分析并保存这两点之间的全部方块。

投影仪识别到正确槽位中的自定义模式物品后，会持续在上方显示随机全息图，表示当前结构不属于预设形状，这是正常现象。若要调整力场相对投影仪的位置，可在带方向箭头的槽位中加入[移动模块](@mffs:translation_module)。

## 调整力场

和其他模式一样，自定义力场也能分别通过[旋转模块](@mffs:rotation_module)和[尺寸模块](@mffs:scale_module)旋转、缩放。
