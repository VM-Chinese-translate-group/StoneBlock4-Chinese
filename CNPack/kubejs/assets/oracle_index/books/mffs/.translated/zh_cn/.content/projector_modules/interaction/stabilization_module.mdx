# 固化模块

在 [](@mffs:projector) 中安装固化模块，可将力场变为实体结构。投影仪不再生成断电后消失的能量屏障，而是使用玩家提供的真实方块搭建结构。

这样便能按照力场图案建造完全相同的实体建筑，关闭投影仪后也会保留。结构的坚固程度取决于所用方块；只要投影仪供能充足、补充方块足够，被破坏的部分就会持续自动修复。

固化过程比普通力场投影更慢，也消耗更多力场子，但配合 [](@mffs:custom_mode) 可以实现极为丰富的用途。

例如，可以建造遭到[苦力怕](@creeper)炸毁后自动修复的建筑。加入[速度模块](@mffs:speed_module)还能同时固化多个方块。

## 使用方法

- 在力场投影仪任意一侧放置箱子，装入搭建结构所需的方块。
- 将固化模块装进投影仪的矩阵槽，设置好力场，然后激活投影仪。
- 投影仪会按槽位顺序取用相邻箱子里的方块。箱内混放多种方块时，建出的结构也会混用这些材料。

## 自定义模式下的用法

自定义模式会记录扫描结构中每个方块的精确位置和类型，因此 [](@mffs:custom_mode) 的固化方式与其他模式不同：投影仪不会依次随意取材，而是只取用与原结构对应的方块。

每个方块都会按记录的类型与位置准确放置。缺少所需材料时，投影仪会暂停，直到补齐。
